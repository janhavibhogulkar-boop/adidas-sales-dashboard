# Adidas Sales Analytics Dashboard

## Project Overview
This project analyzes Adidas US sales data and presents the results through an interactive Streamlit dashboard.

## Objectives
- Analyze total sales and operating profit.
- Compare sales across product categories and regions.
- Visualize monthly sales trends.
- Display important sales performance metrics.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Streamlit
- Google Colab

## Dataset
The project uses the Adidas US Sales dataset containing information about products, regions, invoice dates, total sales, and operating profit.

## Dashboard Features
- Total sales and operating profit metrics
- Sales by product
- Sales by region
- Monthly sales trend
- Operating profit by product
- Sales data preview
- Downloadable cleaned data

## How to Run the Project
1. Install Python on your computer.
2. Open a terminal in the project folder.
3. Install the required libraries:

   `pip install -r requirements.txt`

4. Run the dashboard:

   `streamlit run app.py`

5. Upload the cleaned Adidas sales Excel or CSV file when prompted.

## Expected Result
An interactive dashboard that helps users explore Adidas sales performance and compare products, regions, and profitability.
